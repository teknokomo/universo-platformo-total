# @universo-platformo/auth-srv

Часть монорепозитория [Universo Platformo Total.js](../../README-RU.md).

[English version](./README.md)

## Описание

Бэкенд-сервис Total.js v5 для аутентификации. Обрабатывает вход, регистрацию, выход и управление сессиями через Supabase Auth.

## Использование

```bash
pnpm install
```
