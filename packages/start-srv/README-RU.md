# `@universo-platformo/start-srv`

Приложение Total.js v5 — стартовая страница для гостей, стартовая страница для авторизованных пользователей и аутентификация через Supabase.

Этот пакет является **нативной реализацией** стартового опыта Universo Platformo на базе Total.js Platform.
Он использует **исключительно** технологии из экосистемы Total.js Platform — без React, Vite, MUI.

---

## Технологический стек (100% Total.js Platform)

| Слой | Технология |
|------|-----------|
| **Сервер** | [Total.js v5](https://www.totaljs.com/) (Node.js, компиляция не требуется) |
| **Frontend UI** | [jComponent](https://www.totaljs.com/jcomponent/) (загружается с CDN, 300+ веб-компонентов) |
| **SPA-маршрутизация** | jComponent `NAV` / `ROUTE` (клиентская навигация без перезагрузки страницы) |
| **Управление состоянием** | jComponent `SET` / `GET` / `UPD` / `WATCH` (привязка данных по пути) |
| **Аутентификация** | [Supabase](https://supabase.com/) (только на стороне сервера через `@supabase/supabase-js`, httpOnly cookies) |
| **Стили** | Чистый CSS с пользовательскими свойствами (препроцессор не требуется) |

> **Почему не React/Vite/MUI?**  
> Предыдущая реализация (`start-frt`, `auth-frt`) использовала React + MUI + Vite, которые _не входят_
> в экосистему Total.js Platform. jComponent — это собственная встроенная UI-библиотека Total.js,
> которая поставляется с каждым Total.js приложением и не требует шага сборки.

## Возможности

- **Стартовая страница для гостей** — секция hero, сетка функций, отзывы, форма входа/регистрации
- **Стартовая страница для авторизованных** — навигационная панель, мастер настройки (пошаговый), дашборд с быстрыми действиями
- **Аутентификация через Supabase** — вход, регистрация, выход, восстановление сессии при перезагрузке страницы (всё через серверные маршруты `/api/auth/*`)
- **Паттерны jComponent** — состояние `SET`/`GET`, SPA-навигация `ROUTE`, хук загрузки `ON('ready')`
- **Сессии на основе httpOnly cookies** — учётные данные Supabase никогда не покидают сервер; браузер получает только httpOnly cookies

## Конфигурация

Скопируйте `.env.example` (корень репозитория) в `.env` и заполните значения Supabase:

```env
PORT=4000
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_ANON_KEY=your-anon-key
```

`SUPABASE_ANON_KEY` используется **только на сервере** — он никогда не передаётся в браузер.
Вся аутентификация проходит через серверные маршруты `/api/auth/*`, а браузер получает
только httpOnly сессионные cookies.

## Как работает jComponent

```
┌─────────────────────────────────────────────────────────┐
│ Сервер Total.js (Node.js)                               │
│  • Читает SUPABASE_URL и SUPABASE_ANON_KEY из env       │
│  • Обрабатывает маршруты /api/auth/* (вход, регистрация) │
│  • Выдаёт httpOnly сессионные cookies браузеру           │
│  • Отдаёт index.html для ВСЕХ GET-маршрутов (SPA)       │
│  • Отдаёт статические файлы из public/ (/css/, /js/)    │
└────────────────────────┬────────────────────────────────┘
                         │ HTML-ответ
                         ▼
┌─────────────────────────────────────────────────────────┐
│ Браузер                                                 │
│  jComponent (CDN) загружается и вызывает ON('ready')    │
│  → UP.init() запускается                                │
│     → GET /api/auth/session проверяет сессию             │
│     → Показывает #page-guest (гость) или #page-auth     │
│  jComponent SET/GET управляет всем состоянием UI        │
│  jComponent ROUTE обрабатывает навигацию вперёд/назад   │
│  Все операции авторизации идут через /api/auth/* (бэкенд)│
└─────────────────────────────────────────────────────────┘
```

## Справочник API

### `window.UP` — Публичное API приложения

| Метод | Описание |
|-------|----------|
| `UP.showAuthSection()` | Прокрутить до формы аутентификации и показать её |
| `UP.hideAuthSection()` | Скрыть форму аутентификации |
| `UP.scrollToFeatures()` | Плавная прокрутка к секции функций |
| `UP.switchTab(tab)` | Переключение между вкладками `'login'` и `'register'` |
| `UP.handleLogin(event)` | Обработка отправки формы входа |
| `UP.handleRegister(event)` | Обработка отправки формы регистрации |
| `UP.handleLogout()` | Выход текущего пользователя |
| `UP.onboardingNext(step)` | Переход к шагу настройки (1, 2 или 3) |
| `UP.onboardingComplete()` | Пометить настройку как завершённую |
| `UP.showDashboard()` | Пропустить настройку и показать дашборд |

## Связь с React-пакетами

Пакеты `start-frt` и `auth-frt` в этом монорепозитории являются **альтернативными реализациями на React**.
`start-srv` заменяет их нативным подходом на Total.js Platform.

| Пакет | Стек | Статус |
|-------|------|--------|
| `start-srv` | Total.js v5 + jComponent (CDN) | ✅ Нативный Total.js Platform |
| `start-frt` | React + MUI + Vite | ⚠️ Альтернатива на React (не нативный Total.js) |
| `auth-frt` | React + MUI + Vite | ⚠️ Альтернатива на React (не нативный Total.js) |
